# Lumeriar Event System

Event management system to be used by Lumeriar Robotics

## Admin Features: 
- Create, manage and view Events, Judges, Teams, Schools, etc.

## Coach Features: 
- Register and view teams entered in competitions
- View scores for their teams, and create appeal requests for any scores they want to appeal

## Judge Features: 
- View and assign scores for the teams that they are in charge of at events
- View appeal requests made for their events and make any necessary changes
